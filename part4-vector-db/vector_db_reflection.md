## Vector DB Use Case

A traditional keyword-based search would not be sufficient for searching through long legal documents because it relies on exact word matching. If the user searches using different wording, relevant results may not be found.

Vector databases use embeddings to understand the semantic meaning of text. This allows users to search using natural language queries, and the system can return results based on meaning rather than exact keywords.

For example, a query like "termination clause" can still match relevant sections even if the exact phrase is not present.

Therefore, vector databases are more effective for applications like legal document search, where understanding context and meaning is important.
